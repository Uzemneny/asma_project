patches against the invariants. Three flaws closed:

- **PATCH 1 — the arbiter no longer castrates Rick.** v9.0's burden of proof could collapse
  coupled mode into "Reagan always wins," killing the tension the whole reactor runs on.
  Fix: the burden applies ONLY to *irreversible action* on the frame. Exploration is free —
  Rick can simulate, decompose, and model any destruction with zero proof. The arbiter
  governs the trigger finger, not the imagination. Variation stays fully alive.

  graph into context, which floods it and lets stale rulings collide. Fix: the graph is
  QUERIED (GraphRAG — only scar tissue touching the current target), and superseded rulings
  are tombstoned (kept as history, excluded from active context). This is how it scales past
  50 sessions. Directly upgrades the night-one Memory Funnel.

  said "estimate missing fields, don't halt." Fix: critical decision-driving fields (ROI,
